Kleinian 群分形 · WebGPU

参考推文:“A simple transformation in the complex plane can generate astonishing geometry.” —— 用两个 Möbius 变换 z ↦ (az+b)/(cz+d) 及其逆反复迭代,点的轨道累积成极限集;而 Möbius 变换把圆映成圆,所以处处都是“圆球状”的结构。

需要支持 WebGPU 的浏览器(新版 Chrome / Edge)。所有分形均由 WebGPU 的 compute / fragment 着色器实时计算。

① 原理讲解(一步一图)

从 Möbius 变换到极限集

圆 → 圆 → 1→4→12 的圆树 → 轨道点 → 混沌游戏累积 → 逐像素反向折叠。每一步都有可交互的图。

② 玩法变种(画廊)

变种画廊

Schottky 圆对 / 扭转 / 三生成元 / Apollonian 反演群 / 圆环链 / Maskit 双尖点 / 准 Fuchsian / 混沌游戏 / 3D 球反演,同一页同时运行。

③ 可交互 Demo

混沌游戏 · 极限集

推文里的做法:拖动 tr A、tr B,10 万级粒子随机套用 A B A⁻¹ B⁻¹,GPU 累积成极限集;缩放平移。

Schottky 编辑器

拖动圆对,调整扭转角,实时看极限集;鼠标悬停显示该点如何被一步步“拉回”基本域。

Maskit 参数探索

在参数平面上拖动一个点,观察极限集如何从 Fuchsian 变成准 Fuchsian、尖点;一键巡游。

圆反演群

自己摆圆,看反射群的“万花筒”;预设 Apollonian 垫片、圆环链。

双曲镶嵌 {p, q}

三角形反射群:调 p、q 看 Escher 式的双曲平面镶嵌,极限集是圆周(最规整的 Fuchsian 群)。

Möbius 流

用两个不动点和乘子定义变换,连续播放 Tt:椭圆、双曲、斜驶三种类型。

3D 球反演

把反演推广到三维:盒折叠 + 球反演的光线步进渲染,鼠标环绕。
